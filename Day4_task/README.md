## Quick Reference — Key Concepts Covered
 
| Concept | Where Used | Description |
|---------|------------|-------------|
| `class` & `__init__` | [Task1](./student_report.py), [Task5](./library_system.py), [Task8](./fraction_class.py), [Task9](./inventory.py) | Blueprint for creating objects; `__init__` initializes instance attributes |
| Instance vs Class Variables | [Task1](./student_report.py) | Instance variables are unique per object; class variables are shared across all instances |
| `__str__` | [Task1](./student_report.py), [Task8](./fraction_class.py), [Task9](./inventory.py) | Dunder method that defines how an object is printed with `print()` |
| `__add__`, `__eq__`, `__lt__` | [Task8](./fraction_class.py) | Dunder methods that enable `+`, `==`, and `<` operators on custom objects |
| `@total_ordering` | [Task8](./fraction_class.py) | Decorator that auto-generates `__le__`, `__gt__`, `__ge__` from `__eq__` and `__lt__` |
| Inheritance & `super()` | [Task5](./library_system.py) | Child class inherits from parent; `super()` calls the parent's `__init__` or method |
| Method Overriding | [Task5](./library_system.py) | Child class redefines a parent method to change or extend its behaviour |
| `isinstance()` | [Task5](./library_system.py) | Checks if an object belongs to a class or any of its parent classes |
| List Comprehension | [Task2](./comprehension_drills.py) | Concise one-line syntax to build lists: `[expr for item in iterable if condition]` |
| Dict & Set Comprehension | [Task2](./comprehension_drills.py) | Same idea as list comprehension but produces `{}` dicts or `{}` sets |
| Type Hints | [Task1](./student_report.py), [Task3](./file_records.py), [Task4](./typed_calculator.py), [Task5](./library_system.py), [Task6](./config_manager.py), [Task8](./fraction_class.py), [Task9](./inventory.py) | Annotates function parameters and return types for clarity and tooling support |
| `Optional[T]` | [Task4](./typed_calculator.py) | From `typing` — means a function can return type `T` or `None` |
| `csv.writer` vs `DictWriter` | [Task3](./file_records.py), [Task9](./inventory.py) | `writer` uses positional lists; `DictWriter` uses named fields — safer and clearer |
| `json.dump` vs `json.dumps` | [Task6](./config_manager.py) | `dump` writes to a file; `dumps` returns a JSON-formatted string in memory |
| `@staticmethod` | [Task9](./inventory.py) | Method that belongs to a class but needs no `self` or `cls` — acts like a plain function |
| `@classmethod` | [Task9](./inventory.py) | Method that receives `cls` — useful when subclasses need to return their own type |
| `math.gcd` | [Task8](./fraction_class.py) | Finds the Greatest Common Divisor — used to simplify fractions |
| Pandas `groupby()` | [Task7](./pandas_explore.py) | Groups rows by a column value and applies aggregation functions |
| Pandas `nlargest()` | [Task7](./pandas_explore.py) | Returns the top N rows by a given column — cleaner than sort + slice |
| Pandas filtering | [Task7](./pandas_explore.py) | Boolean indexing: `df[df["col"] > value]` returns matching rows |
| `if __name__ == "__main__"` | [Task4](./typed_calculator.py), [Task7](./pandas_explore.py), [Task8](./fraction_class.py), [Task9](./inventory.py) | Ensures test code only runs when the file is executed directly, not when imported |
